# Set Up Project Virtual Environment and Dependencies

## Task Brief
Initialize a Python virtual environment for the data pipeline project and create a requirements.txt file with all dependencies.

## Scenario
Your team needs a reproducible development setup for the data pipeline project to ensure all developers use consistent package versions.

## Deliverables
- Virtual environment initialized
- requirements.txt with project dependencies

## Success Criteria
- Virtual environment activates without errors
- requirements.txt lists all required packages
