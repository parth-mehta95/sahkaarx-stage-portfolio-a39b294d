## Task Brief
Extend the DataHandler class to execute the SQL JOIN queries and load joined data into the pipeline.

## Scenario
Extend your DataHandler class with a method to execute SQL JOIN queries and return results as Python objects for downstream processing.

## Deliverables

## Success Criteria
- Executes JOIN queries successfully
- Returns data as structured objects
