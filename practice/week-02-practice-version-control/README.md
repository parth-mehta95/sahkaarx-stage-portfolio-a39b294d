# Practice: Version Control

## Task Brief
Build a data loading module, submit a pull request, address reviewer feedback, resolve integration conflicts, and merge to main branch.

Review a teammate pull request, provide constructive feedback on code quality, and approve or request changes.

## Scenario
Your data team needs a production-ready data loading module. Create a feature branch, build the module, submit a PR, handle feedback, resolve conflicts, and merge.

Your team practices peer code review. Review a teammate pull request, provide feedback on code quality, and approve or request changes.

## Deliverables
- Updated GitHub repository with merged data loading module
- Pull request with conflict resolution history

## Success Criteria
- Conflict Resolution: Resolve merge conflicts between feature and main branch using Git conflict resolution techniques
- Pull Requests: Create pull request with clear description, receive and address reviewer feedback, and complete merge workflow
